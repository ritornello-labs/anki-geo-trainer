Learn the shapes and locations of **nine Australian states and territories represented in the source map** through four spatial-recall games: **35 notes / 35 cards**.

## Identify a state or territory

Name the state or territory containing the dot on a map without internal borders. Reveal its name and outline.

![Identify Queensland in real Anki](https://ritornello.dev/media/ankiweb/2026-10-04-v1/geo-trainer-australia-subdivisions/point.gif)

## Place the shape

Drag Queensland's silhouette into position on the blank map, then reveal the answer and native distance feedback.

![Place Queensland in real Anki](https://ritornello.dev/media/ankiweb/2026-10-04-v1/geo-trainer-australia-subdivisions/place.gif)

## Sketch in context

Draw Queensland where it belongs on the map. The answer compares your outline with its shape and position.

![Sketch Queensland in real Anki](https://ritornello.dev/media/ankiweb/2026-10-04-v1/geo-trainer-australia-subdivisions/sketch.gif)

## Draw from memory

Recall Queensland's outline on a square canvas without a map or aspect-ratio hint. The answer compares shape independently of drawing size and position.

![Draw Queensland in real Anki](https://ritornello.dev/media/ankiweb/2026-10-04-v1/geo-trainer-australia-subdivisions/draw.gif)

## Using the pack

There are **9 identification, 9 placement, 8 contextual sketch and 9 outline cards**, in four task subdecks. Coverage: New South Wales, Victoria, Queensland, South Australia, Western Australia, Tasmania, the Northern Territory, the Australian Capital Territory and Jervis Bay Territory. Jervis Bay omits contextual sketching under the existing geometry-selection rule; it retains the other three games. External territories are outside this pack’s source-map scope.

Games show feedback and a suggested grade; **you choose Anki's grade yourself**. Identification uses ordinary recall. Geometry and game code are bundled for offline study.

This component will also be included in [GeoTrainer's full edition](https://ankiweb.net/shared/info/908455862), whose update ships after the components. Shared scopes retain the same model IDs, leaf deck IDs and note GUIDs, so overlapping imports update the same notes.

## Source edition

Geometry uses [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) public-domain administrative data with the project's own projection. This is a simplified map exercise, rather than a detailed boundary survey. [Jervis Bay Territory](https://www.infrastructure.gov.au/territories-regions/territories/jervis-bay-territory) is included as its own map unit. The full scope and reproducible build are recorded in the repository.
