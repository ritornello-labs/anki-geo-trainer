# Subdivision listing pattern

U.S. States is the first reference implementation, at Elvis's October 3 request. Elvis approved its complete four-game listing batch on October 3; use this pattern for subsequent country batches, which each still need their own preview approval.

- Use a readable country/unit title, the standard Ritornello banner, and gallery navigation.
- Lead with the spatial learning task and exact accepted units, notes and cards. Name relevant exclusions; never assume every country has 50 units or four cards for every unit.
- Present the distinct accepted tasks in learning order: identification, silhouette placement, contextual sketch, outline drawing. Omit unavailable tasks rather than inventing them.
- Use one meaningful real-Anki GIF per distinct interactive task. A coherent example across tasks makes the progression easy to compare. Similar static templates share a representative demo.
- Show an unhinted front, a native gesture/recall attempt when the task accepts input, and the actual answer/feedback. Reject dialogs, empty attempts, clipping and decorative mock cards.
- Explain separate subdecks, self-grading and offline clients briefly. Preserve source attribution, visible full-URL GitHub link, full-edition link and stable support URL. No donation material goes on cards.
- Build from current source, prove per-task membership and stable shared identities, and capture only in disposable Anki seeded by that exact artifact. AnkiWeb source-deck names require separate Publisher staging verification.
- Preview the full listing and wait for image approval. After submission, archive the exact submitted artifact in a tagged GitHub release and update the website/component-link register.
