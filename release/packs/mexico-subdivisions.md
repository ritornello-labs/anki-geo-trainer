Learn the shapes and locations of **Mexico’s 31 states and Mexico City** through four spatial-recall games: **128 notes / 128 cards**, covering all 32 federal entities.

## Identify an entity

Name the entity containing the dot on a map without internal borders. Reveal its name and outline.

![Identify Jalisco in real Anki](https://ritornello.dev/media/ankiweb/2026-10-05-v1/geo-trainer-mexico-subdivisions/point.gif)

## Place the shape

Drag Jalisco's silhouette into position on the blank map, then reveal the answer and native distance feedback.

![Place Jalisco in real Anki](https://ritornello.dev/media/ankiweb/2026-10-05-v1/geo-trainer-mexico-subdivisions/place.gif)

## Sketch in context

Draw Jalisco where it belongs on the map. The answer compares your outline with its shape and position.

![Sketch Jalisco in real Anki](https://ritornello.dev/media/ankiweb/2026-10-05-v1/geo-trainer-mexico-subdivisions/sketch.gif)

## Draw from memory

Recall Jalisco's outline on a square canvas without a map or aspect-ratio hint. The answer compares shape independently of drawing size and position.

![Draw Jalisco in real Anki](https://ritornello.dev/media/ankiweb/2026-10-05-v1/geo-trainer-mexico-subdivisions/draw.gif)

## Using the pack

There are **32 identification, 32 placement, 32 contextual sketch and 32 outline cards**, in four task subdecks. Every entity has all four exercises.

Games show feedback and a suggested grade; **you choose Anki's grade yourself**. Identification uses ordinary recall. Geometry and game code are bundled for offline study.

This component will also be included in [GeoTrainer's full edition](https://ankiweb.net/shared/info/908455862), whose update ships after the components. Shared scopes retain the same model IDs, leaf deck IDs and note GUIDs, so overlapping imports update the same notes.

## Source edition

Geometry uses [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) public-domain administrative data with the project's own projection. This is a simplified map exercise, rather than a detailed boundary survey. The labels use **Mexico City** in place of the older Distrito Federal name and **State of Mexico** to distinguish that state from the country. The [INEGI entity catalog](https://www.inegi.org.mx/app/areasgeograficas/) provides the current names. Stable note keys and geometry are retained; the full scope and reproducible build are recorded in the repository.
