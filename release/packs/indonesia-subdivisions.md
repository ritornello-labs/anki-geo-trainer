Learn the shapes and locations of **Indonesia’s 38 provinces** through four spatial-recall games: **151 notes / 151 cards**, including North Kalimantan and the four new Papua provinces.

## Identify a province

Name the province containing the dot on a map without internal borders. Reveal its name and outline.

## Place the shape

Drag Kalimantan Utara's silhouette into position on the blank map, then reveal the answer and native distance feedback.

## Sketch in context

Draw Kalimantan Utara where it belongs on the map. The answer compares your outline with its shape and position.

## Using the pack

There are **38 identification, 38 placement, 37 contextual sketch and 38 outline cards**, in four task subdecks. Jakarta is magnified on the whole-country map for identification and placement; its contextual Sketch exercise is omitted at this scale. Its standalone Draw card uses the real outline.

Games show feedback and a suggested grade; **you choose Anki's grade yourself**. Identification uses ordinary recall. Geometry and game code are bundled for offline study.

This component will also be included in [GeoTrainer's full edition](https://ankiweb.net/shared/info/908455862), whose update ships after the components. Shared scopes retain the same model IDs, leaf deck IDs and note GUIDs, so overlapping imports update the same notes.

## Source edition

This is a **38-province map**, replacing the old 33-province edition. It adds **Kalimantan Utara, Papua Selatan, Papua Tengah, Papua Pegunungan and Papua Barat Daya**, and updates the reduced boundaries of Kalimantan Timur, Papua and Papua Barat. Existing note identities are retained for updates. [Indonesia's official statistics](https://www.bps.go.id/en/statistics-table/2/MTM1IzI%3D/jumlah-desa-menurut-provinsi-dan-) use the current 38-province scope.

Geometry comes from [Peta Nusa / Laravel Nusa](https://github.com/creasico/laravel-nusa), distributed by [Indonesia-GeoJSON](https://github.com/AlfianAliM/Indonesia-GeoJSON), under the MIT license (© Creasi.co). The pinned export cites Kepmendagri No 300.2.2-2138 Tahun 2025. Coastlines and islands are simplified for study; this is an administrative map exercise rather than a detailed boundary survey. The source edition, full license notice and reproducible build are recorded in the repository.
